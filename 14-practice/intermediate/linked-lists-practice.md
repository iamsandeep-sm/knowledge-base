# Linked Lists Practice (Intermediate)

Related notes: [Linked Lists](../../13-dsa-with-python/linked-lists.md)

> Intermediate: comfortable with the basics, now combining ideas. **Questions only, no solutions.** Write and run your own code, and test it on empty, single-item and large inputs.

## Practice Questions

1. Create a `Node` class and a `LinkedList` class with `append`, `prepend`, `insert_at(index, value)`, `delete(value)`, `find(value)`, `__len__` and `__iter__`.
2. Convert a Python list into a linked list and a linked list back into a Python list.
3. Reverse a singly linked list iteratively, then recursively.
4. Find the middle node using slow and fast pointers. What do you return for an even number of nodes?
5. Detect whether a linked list has a cycle, first with a `set` and then with Floyd's algorithm (`O(1)` space).
6. Remove the `n`-th node from the end in one pass.
7. Merge two sorted linked lists into one sorted list.
8. Remove duplicates from a sorted linked list.
9. Check whether a linked list is a palindrome in `O(1)` extra space.
10. Delete a node when you are given **only that node** (not the head), assuming it is not the tail.
11. Remove every node with a given value. Use a dummy node to handle the head neatly.
12. Find the node where two linked lists **intersect**, if any.
13. Add two numbers stored as linked lists with digits in reverse order. Example: `2 -> 4 -> 3` plus `5 -> 6 -> 4` gives `7 -> 0 -> 8`.
14. Group all nodes at odd positions followed by all nodes at even positions, keeping the order inside each group.
15. Rotate a linked list to the right by `k` places.
16. Build a `DoublyLinkedList` with `append`, `remove(node)`, forward and backward iteration. Why is removal `O(1)` here?
17. Implement a stack and a queue using a linked list so every operation is `O(1)`.
18. Write a function that returns the length of a linked list recursively. When would this fail?
