# Arrays and Strings Practice (Intermediate)

Related notes: [Arrays and Strings](../../13-dsa-with-python/arrays-and-strings.md)

> Intermediate: comfortable with the basics, now combining ideas. **Questions only, no solutions.** Write and run your own code, and test it on empty, single-item and large inputs.

## Practice Questions

1. Given a **sorted** list and a target, use two pointers to return the indices of the two numbers that add up to the target. Example: `[2, 7, 11, 15]`, target `9` gives `(0, 1)`.
2. Reverse a list **in place** without using slicing, `reverse()` or `reversed()`.
3. Move all zeros to the end of a list **in place**, keeping the order of the other items. Example: `[0, 1, 0, 3, 12]` becomes `[1, 3, 12, 0, 0]`.
4. Remove duplicates from a **sorted** list in place and return the new length.
5. Find the maximum sum of any `k` consecutive items using a sliding window. Example: `[2, 1, 5, 1, 3, 2]`, `k = 3` gives `9`.
6. Find the length of the longest substring without repeating characters. Example: `"abcabcbb"` gives `3`.
7. Build a prefix-sum list and use it to answer many range-sum queries `sum(items[i:j])` in `O(1)` each.
8. Find the maximum sum of a contiguous subarray (Kadane's algorithm). Example: `[-2, 1, -3, 4, -1, 2, 1, -5, 4]` gives `6`.
9. Rotate a list to the right by `k` places in place, using the three-reversals trick.
10. Check whether two strings are anagrams in two different ways: sorting, and counting characters.
11. Check whether a string is a palindrome, ignoring case, spaces and punctuation. Example: `"A man, a plan, a canal: Panama"` is `True`.
12. Find the longest common prefix of a list of strings. Example: `["flower", "flow", "flight"]` gives `"fl"`.
13. Compress a string by counting consecutive characters. Example: `"aaabbc"` becomes `"a3b2c1"`. Then write the decompressor.
14. Transpose a square matrix, then rotate it 90 degrees clockwise.
15. A list holds the numbers `0` to `n` with exactly one missing. Find the missing number in `O(n)` time and `O(1)` space, in two different ways.
16. Merge two sorted lists into one sorted list without using `sort()` or `sorted()`.
17. Find the second largest distinct number in a list in a single pass.
18. Count the vowels, consonants, digits and spaces in a string in one loop.
