# Graphs Practice (Intermediate)

Related notes: [Graphs](../../13-dsa-with-python/graphs.md)

> Intermediate: comfortable with the basics, now combining ideas. **Questions only, no solutions.** Write and run your own code, and test it on empty, single-item and large inputs.

## Practice Questions

1. Build an adjacency list from an edge list, once for an undirected graph and once for a directed graph. Print the degree of each vertex.
2. Write BFS that returns the order in which vertices are visited. Why must you mark a vertex as visited when it is added to the queue?
3. Write DFS recursively and iteratively. Do they always give the same order? Explain.
4. Check whether a path exists between two vertices.
5. Find the **shortest path** (fewest edges) between two vertices and return the actual path.
6. Count the connected components of an undirected graph.
7. Detect a cycle in an **undirected** graph.
8. Detect a cycle in a **directed** graph. Why does the undirected approach give wrong answers here?
9. Count the number of islands in a grid of `"1"` (land) and `"0"` (water).
10. Flood fill: starting from a cell, change all connected cells of the same colour to a new colour.
11. Rotting oranges: each minute, rotten oranges rot their 4 neighbours. Return the minutes until none are fresh, or `-1`. Use multi-source BFS.
12. Number of provinces: given an `n x n` matrix where `m[i][j] = 1` means cities are connected, count the groups.
13. Course schedule: given prerequisites, can you finish all courses? Solve using topological sort.
14. Check whether a graph is **bipartite** (can be two-coloured).
15. Find the vertex with the highest degree, and the vertices that have no edges at all.
16. Clone an undirected graph given a reference to one node.
17. Find the shortest path through a maze given as a list of strings, returning the number of steps.
18. Convert between an adjacency list and an adjacency matrix, in both directions.
