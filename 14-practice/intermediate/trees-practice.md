# Trees Practice (Intermediate)

Related notes: [Trees](../../13-dsa-with-python/trees.md)

> Intermediate: comfortable with the basics, now combining ideas. **Questions only, no solutions.** Write and run your own code, and test it on empty, single-item and large inputs.

## Practice Questions

1. Build a binary tree by hand and write pre-order, in-order and post-order traversals recursively.
2. Write in-order and pre-order traversals **iteratively** with your own stack.
3. Level-order traversal that returns a list of lists, one per level.
4. Compute the height, the number of nodes and the number of leaves of a binary tree.
5. Write a BST class with `insert`, `search`, `minimum`, `maximum` and an in-order generator.
6. Add `delete` to the BST. Test all three cases: leaf, one child, two children.
7. Check whether a binary tree is a valid BST. Show a tree that fools the naive `left < node < right` check.
8. Invert (mirror) a binary tree.
9. Check whether two trees are identical, and whether a tree is symmetric.
10. Does a root-to-leaf path exist whose values add to a target sum? Then return **all** such paths.
11. Return the right-side view of a binary tree.
12. Convert a **sorted list** into a height-balanced BST.
13. Find the minimum depth and the maximum depth of a binary tree.
14. Find the lowest common ancestor of two values in a BST using its ordering.
15. Find the `k`-th smallest value in a BST.
16. Check whether a tree is height-balanced.
17. Return all root-to-leaf paths as strings such as `"1->2->5"`.
18. Implement a `Trie` with `insert`, `search` and `starts_with`, then add autocomplete.
19. Use `heapq` to find the `k` largest numbers in a list, then to merge several sorted lists into one.
20. Walk a real folder tree with `os.walk` or `pathlib` and print it indented like a tree, with a count of files per folder.
