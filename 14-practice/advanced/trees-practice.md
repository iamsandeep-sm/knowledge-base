# Trees Practice (Advanced)

Related notes: [Trees](../../13-dsa-with-python/trees.md)

> Advanced: harder problems that need a clear plan before coding. **Questions only, no solutions.** Write and run your own code, and test it on empty, single-item and large inputs.

## Practice Questions

1. **Serialize and deserialize** a binary tree to a string and back, so the original tree is rebuilt exactly.
2. Build a binary tree from its **pre-order and in-order** traversals. Explain why in-order alone is not enough.
3. Find the diameter of a binary tree (longest path between any two nodes).
4. Find the **maximum path sum** in a binary tree, where a path may start and end at any node.
5. Zigzag level-order traversal: left to right on one level, right to left on the next.
6. Find the lowest common ancestor of two nodes in a general binary tree (not a BST).
7. Vertical-order traversal: group nodes by their column offset from the root.
8. Flatten a binary tree into a right-leaning linked list in place, following pre-order.
9. Traverse a binary tree in-order with `O(1)` extra space using **Morris traversal**.
10. Add wildcard search `.` to a trie (`".ad"` matches `"bad"`). Then solve **Word Search II** with a trie and backtracking on a grid.
11. Implement an **AVL tree** `insert` with left and right rotations. Verify the height stays `O(log n)` for sorted input.
12. Find the median of a stream of numbers using two heaps (a max-heap and a min-heap).
13. Count the structurally unique BSTs that can store `1..n` (Catalan numbers). Solve with recursion plus memoization, and with a loop.
14. Two nodes of a BST were swapped by mistake. Recover the tree without changing its structure.
15. Count the paths in a binary tree that add up to a target (paths may start and end anywhere, but go downward).
16. Check whether one tree is a **subtree** of another.
17. Implement a priority queue as a binary heap in a list (with `push`, `pop`, `peek`, sift-up and sift-down), without `heapq`.
