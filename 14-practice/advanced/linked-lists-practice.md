# Linked Lists Practice (Advanced)

Related notes: [Linked Lists](../../13-dsa-with-python/linked-lists.md)

> Advanced: harder problems that need a clear plan before coding. **Questions only, no solutions.** Write and run your own code, and test it on empty, single-item and large inputs.

## Practice Questions

1. Reverse the nodes of a linked list **in groups of `k`**. Example: `1->2->3->4->5`, `k = 2` gives `2->1->4->3->5`.
2. Reverse only the part of a list between positions `m` and `n`, in one pass.
3. Find the node where a cycle begins, and also the length of the cycle.
4. Sort a linked list in `O(n log n)` time and `O(log n)` space using merge sort.
5. Merge `k` sorted linked lists using a min-heap. State the complexity.
6. Implement an **LRU cache** with a dictionary and a doubly linked list, with `O(1)` `get` and `put`.
7. Deep-copy a linked list in which every node has a `random` pointer to any node, in `O(1)` extra space (interleaving trick).
8. Reorder a list `L0 -> L1 -> ... -> Ln` into `L0 -> Ln -> L1 -> Ln-1 -> ...` in place.
9. Flatten a multilevel doubly linked list, where nodes may have a `child` list.
10. Swap every two adjacent nodes by changing links, not values.
11. Partition a list around a value `x` so all smaller nodes come before the rest, keeping the relative order.
12. Add two numbers stored as linked lists with digits in **forward** order, without reversing the input lists.
13. Implement a **skip list** with search and insert, and compare its search time with a plain linked list.
14. Given a list with a cycle, remove the cycle so it becomes a normal list.
15. Check whether two linked lists are equal **without** converting them to Python lists and without recursion.
