# Arrays and Strings Practice (Advanced)

Related notes: [Arrays and Strings](../../13-dsa-with-python/arrays-and-strings.md)

> Advanced: harder problems that need a clear plan before coding. **Questions only, no solutions.** Write and run your own code, and test it on empty, single-item and large inputs.

## Practice Questions

1. Return a list where each item is the **product of all the other items**, without using division and in `O(n)` time. Example: `[1, 2, 3, 4]` gives `[24, 12, 8, 6]`.
2. Trapping rain water: given bar heights such as `[0, 1, 0, 2, 1, 0, 1, 3, 2, 1, 2, 1]`, compute how much water is trapped. Solve with two pointers in `O(1)` extra space.
3. Container with most water: choose two bars that, with the x-axis, hold the most water. Use two pointers and explain why moving the shorter side is safe.
4. 3Sum: find all **unique** triplets in a list that add up to zero. Avoid duplicate triplets without using a set of results.
5. Find the length of the longest substring that has **at most `k` distinct characters**.
6. Minimum window substring: find the shortest substring of `s` that contains every character of `t` (with counts).
7. Count the subarrays whose sum equals `k`, where the list may contain **negative numbers**. Use prefix sums and a dictionary.
8. Return the elements of a matrix in **spiral order**. Handle non-square matrices.
9. Implement `next_permutation` for a list of numbers, in place. Example: `[1, 2, 3]` becomes `[1, 3, 2]`; `[3, 2, 1]` becomes `[1, 2, 3]`.
10. Merge overlapping intervals. Example: `[[1, 3], [2, 6], [8, 10], [15, 18]]` gives `[[1, 6], [8, 10], [15, 18]]`.
11. Find the contiguous subarray with the **maximum product** (negative numbers and zeros included).
12. Find the start index of every anagram of `p` inside `s` using a fixed-size sliding window.
13. Longest palindromic substring: write the expand-around-centre solution and state its complexity.
14. Set matrix zeroes: if a cell is `0`, set its whole row and column to `0`, using `O(1)` extra space.
15. Given a list where each value is between `1` and `n` and the list has length `n + 1`, find the repeated value without modifying the list and using `O(1)` extra space.
