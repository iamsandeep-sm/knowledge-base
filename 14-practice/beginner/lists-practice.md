# Lists Practice

Related notes: [Lists](../../03-data-structures/lists.md)

## Practice Questions

1. Create a list of 5 numbers. Print the first item, the last item and the middle three items using slicing.
2. Print the list `[10, 20, 30, 40, 50]` in reverse order in three different ways.
3. What is the difference between `append()` and `extend()`? Show with code.
4. What is the difference between `remove()`, `pop()`, `del` and `clear()`?
5. Replace items at index 1 and 2 of `["a", "b", "c", "d"]` with three new items. What is the new length?
6. Using a list comprehension, create a list of squares of even numbers from 1 to 10.
7. Given `["Milo", "Sarah", "Bruno"]`, make a new list with only names that are longer than 4 letters.
8. Sort `["pear", "fig", "banana"]` by length, longest first.
9. What is the difference between `sort()` and `sorted()`? What does `sort()` return?
10. Why does `b = a` not copy a list? Show a shallow copy problem with a nested list, and fix it.
11. Why does `[[0] * 3] * 3` behave unexpectedly? Write the correct version.
12. Remove duplicates from `[3, 1, 3, 2, 1]` while keeping the original order.
13. Flatten `[[1, 2], [3], [4, 5]]` into one list.
14. Join `["Python", "is", "fun"]` into the string `"Python is fun"`.
