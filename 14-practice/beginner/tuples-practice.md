# Tuples Practice

Related notes: [Tuples](../../03-data-structures/tuples.md)

## Practice Questions

1. Create a tuple of 5 fruits and print the **last** item using negative indexing.
2. Write a program to **reverse** a tuple using slicing.
3. Why does `x = (10)` not create a tuple? Fix it.
4. Convert `("a", "b", "c")` → add `"d"` → convert back to a tuple.
5. Unpack `(1, 2, 3, 4, 5)` into `first`, `*middle`, `last`.
6. Write a function that returns the **sum and average** of a tuple of numbers.
7. Count how many times `3` appears in `(1, 3, 3, 7, 3)` and find the index of its first occurrence.
8. Swap two variables without using a third variable.
