# Sets Practice

Related notes: [Sets](../../03-data-structures/sets.md)

## Practice Questions

1. Create a set from the list `[1, 2, 2, 3, 3, 3]` and print it.
2. Why does `x = {}` not create a set? How do you create an empty set?
3. What is the difference between `remove()` and `discard()`? Show with code.
4. Given `A = {1, 2, 3, 4}` and `B = {3, 4, 5, 6}`, find the union, intersection, difference (`A - B`) and symmetric difference.
5. Remove duplicates from `[5, 3, 5, 1, 3]` while **keeping the original order**.
6. Check whether `{"a", "b"}` is a subset of `{"a", "b", "c"}` using both a method and an operator.
7. Write a program to find the common elements between two lists using sets.
8. Why can a tuple be stored inside a set but a list cannot?
9. What is the difference between `union()` and `update()`?
10. What does `{1, True, 1.0}` print, and why?
