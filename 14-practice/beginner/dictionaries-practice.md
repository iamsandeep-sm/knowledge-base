# Dictionaries Practice

Related notes: [Dictionaries](../../03-data-structures/dictionaries.md)

## Practice Questions

1. Create a dictionary of a student (name, age, course) and print the age using both `[ ]` and `get()`.
2. What is the difference between `d['x']` and `d.get('x')` when `'x'` is missing?
3. Add a new key `city` to a dictionary using assignment, then using `update()`.
4. Difference between `pop()`, `popitem()`, `del d[key]`, `clear()` and `del d`. Show each with code.
5. Loop through a dictionary and print `key -> value` for every item.
6. Count how many times each character appears in `"mississippi"`.
7. Given `{'a': 3, 'b': 1, 'c': 2}`, print the dictionary sorted by value and the key with the largest value.
8. Why does `b = a` not copy a dictionary? Show how a shallow copy still shares nested lists, and fix it with `deepcopy`.
9. Create a nested dictionary for 3 students and print each student's name and marks.
10. Merge `{'a': 1, 'b': 2}` and `{'b': 3, 'c': 4}`. Which value of `b` is kept?
11. Create `{1: 1, 2: 4, 3: 9}` using a dictionary comprehension.
12. Why does `{1: 'a', True: 'b'}` have only one key?
