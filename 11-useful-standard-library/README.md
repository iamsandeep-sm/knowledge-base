# Useful Standard Library

Handy built-in modules that come with Python (nothing to install).

| Note | Topic |
|------|-------|
| [math](./math.md) | Constants, `sqrt`, rounding (`ceil`, `floor`, `trunc`), `factorial`, `gcd`, logarithms, trigonometry, `isclose`, `inf` and `nan`, plus `statistics`, `decimal`, `fractions` |
| [random](./random.md) | `random()`, `randint`, `choice`, `sample`, `shuffle`, seeds, weighted choices, `secrets` for security |
| [datetime](./datetime.md) | `date`, `time`, `datetime`, `timedelta`, `strftime`, `strptime`, ISO format, time zones, `calendar` |
| [pathlib](./pathlib.md) | `Path` objects, joining with `/`, reading and writing, `glob`, folders, `shutil` |
| [collections](./collections.md) | `Counter`, `defaultdict`, `deque`, `namedtuple`, `OrderedDict`, `ChainMap` |
| [itertools](./itertools.md) | `count`, `cycle`, `chain`, `islice`, `accumulate`, `groupby`, `product`, `permutations`, `combinations` |
